# Back Office 현재 상태

문서 역할과 읽는 순서는 [README.md](README.md)를 따른다.

기준일: 2026-07-24

## 구현됨

- 관리자 인증 가드, 대시보드 집계, 최근 운영 조치 표시
- 회원 검색·필터·상세 조회와 `ACTIVE ↔ SUSPENDED` 상태 변경
- 관리자 우선·회원 ID 오름차순 회원 목록 정렬
- 상태 변경 이력 저장과 상세 화면의 조치명·처리 시각·사유 표시
- 모집글 제목·모집장 닉네임 검색, 상태·노출 필터, 상세 조회와 `VISIBLE ↔ HIDDEN` 조치
- 모집글 숨김·복구 시 운영 이력 저장 및 대시보드 갱신
- 그룹 상태·활성 인원, 일정, 출석 기록, 활동 기록의 읽기 전용 검색·조회
- 운영 이력의 조치·대상 유형·대상/사유 검색과 페이지 조회
- 라이트·다크 테마, 불투명 알림 드롭다운, 반응형 공통 여백

## 현재 범위

현재 합의한 Back Office 범위는 완료됐다. 새 기능은 별도 요구사항과 설계가 확정된 뒤 시작한다.

## 개발 DB 기준

- 개발 환경의 Back Office 스키마와 테스트 데이터는
  [`sql/moigo_schema_seed.sql`](../../sql/moigo_schema_seed.sql)을 기준으로 한다.
- 이 스크립트는 테이블을 삭제하고 다시 만드는 초기화 스크립트다. 배포·운영 DB 마이그레이션 용도로
  사용하지 않는다.
- 통합 시 확인할 코드·DB·화면 계약은 [integration-guide.md](integration-guide.md)에 정리한다.
