# Back Office 현재 상태

기준일: 2026-07-24

## 구현됨

- 관리자 인증 가드, 대시보드 집계, 최근 운영 조치 표시
- 회원 검색·필터·상세 조회와 `ACTIVE ↔ SUSPENDED` 상태 변경
- 관리자 우선·회원 ID 오름차순 회원 목록 정렬
- 상태 변경 이력 저장과 상세 화면의 조치명·처리 시각·사유 표시
- 라이트·다크 테마, 불투명 알림 드롭다운, 반응형 공통 여백
