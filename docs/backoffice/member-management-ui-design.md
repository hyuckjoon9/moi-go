# 회원 관리 화면 설계

`/backoffice/members.html`은 기존 관리자 인증 가드를 재사용한다. 상단에서 이메일·닉네임 검색,
역할·상태 필터와 페이지 이동을 제공하고, 결과 항목을 선택하면 같은 화면의 상세 패널을 갱신한다.

상세 패널은 프로필, 그룹 요약, 최근 조치를 표시하며 비밀값은 표시하지 않는다. 일반 회원의
`ACTIVE`/`SUSPENDED` 전환은 사유 입력 확인 뒤 실행한다. 성공하면 목록·상세를 다시 읽고,
`409`이면 최신 상세를 다시 읽어 재시도하게 한다. `403`은 권한 메시지, `401`은 로그인 복귀,
그 외 오류는 화면 상태 영역에 표시한다.
