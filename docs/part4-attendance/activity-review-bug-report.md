# 활동 회고(리뷰) 관련 QA 버그 리포트

작성: 장지원 (QA 발견) → 담당: 정자비 (Part4: 출석·활동 기록)
대상 코드: `activity/**` (`ActivityController`, `ActivityService`, `ActivityReview`), 공통 `GlobalExceptionHandler`

## 발견된 증상 

1. 다른 계정으로 활동 회고가 작성 안 됨
2. 회고 저장하면 "연관된 그룹 또는 지원 내역이 있어 삭제할 수 없습니다" 메시지가 뜸 → 운영하는 다른 그룹에서 회고 작성이 안 됨
3. 그룹 홈을 바꿔도 활동 회고가 동일하게 보임
4. 내가 운영자인 새 계정에서는 회고 작성이 회고 조회를 해야 보임
5. "활동 기록을 관리할 권한이 없다"는 메시지가 뜸 (뜰 때마다 케이스가 다른데, 회고 작성 자체가 안 되는 건 공통)

## 정자비님께 확인 요청 사항

1. `GlobalExceptionHandler`의 `DataIntegrityViolationException` 마스킹 문제
2. "회고 작성" 버튼이 실제로 어떤 엔드포인트를 호출하는지 프론트 코드 확인 (기록 API를 잘못 타고 있는 건 아닌지)
3. 그룹 전환 시 회고 목록 재조회 로직 확인
4. 테스트 계정이 실제로 해당 그룹의 활성 그룹원인지 먼저 확인 (그룹원 아니면 정상 차단)
